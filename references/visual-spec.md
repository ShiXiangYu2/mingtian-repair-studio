# 人设、场景与无字幕分镜关键帧

## 用户指定的人设版式

每个角色独立一张白底人设图。上方约1/3是人物正面脸部超特写，自然表情，完整露出头顶、发型以及该角色的耳朵/头部结构，不裁切。下方约2/3均分三块，只显示从颈部以下到脚部的身体，分别为正视、侧视、背视；不再出现头部。双手自然垂落，手脚完整，身体比例和服装结构对齐。纯白背景、无投影、无地平线，不加多余文字。

这是“脸部特写 + 身体三视图”，不等于常规带头全身三视图。用户另要常规三视图时可以补充，不能静默替换这个版式。

阿赶头身相连、没有清楚颈部：下排按脸部以下的躯干/围裙至脚部展示，并在提示词说明是无头身体设计展示；不要为满足“颈部”给阿赶硬加细脖子。机器人下排从颈部连接结构以下开始。对无发型角色应完整露出头顶结构，不凭空加头发。

可用提示词骨架：
“原创动画角色设定板，角色[名称与已确认特征]。画面上方1/3：正面脸部超特写，自然表情，完整头顶/发型/耳朵。下方2/3：等宽三栏，无头的颈部以下至脚部身体三视图，左正面、中侧面、右背面，双手自然垂落，脚完整；比例、衣服与配件一致。纯白背景，无阴影、无字幕、无装饰文字。严格以参考图锁定角色身份。”

## 场景主图

暖阳、木质维修台、低饱和灰绿柜体、深棕线条与奶油色点缀。整理固定布局：门窗、维修台、工具墙、早餐角、灯具、走动通道、主要光源方向。先出无人场景主图，再按脚本需要取机位；不要每个镜头随机换装修和物件位置。
人物图和场景图分别编号版本；批准的图作为后续参考，先核对现有素材再决定是否重画。对只需镜头变化的场景不无故新增主场景。

## 分镜关键帧

一镜一张独立文件 `shot-01.png`。可另做联系表审阅，但拼图不能代替逐镜原图。画幅统一；第1集为16:9横片，抖音竖封面不代表视频必须改9:16。
提示词依次明确：景别、机位高度与观察方向、构图、人物站位与视线、动作起始瞬间、持物/接触关系、道具状态、场景参考和光线。静帧描述不要求同一画面同时表现连续动作，不把“镜头推进”当作一张图的已发生运动。

**关键帧不带字幕**：禁止对白字幕、解说条、镜号、平台logo、水印。对白和字幕仅在脚本指定列保存。订单/日历/招牌如果需要准确中文，预留干净的纸面或牌面，文字在后期添加；是否保留道具自然刻度依剧情决定，“无字幕”不等于删除全部道具信息。

生成前检查首帧与动作起点；生成后看：手臂是否连贯完整、手指/夹爪是否变种、脸和耳是否一致、道具数量、挂绳/铰链、脚是否接地、站位与光向。预算不足不能把缺手图直接交给视频模型赌修复。

需要修图时描述局部改动和保持项，例如“补全画面左下前臂，连续延伸至画外，与手掌连接；保持闹钟、电池仓、另一只手和场景不变；去掉红色圈线”。使用当前图像编辑工具，检查后再进入视频阶段。
