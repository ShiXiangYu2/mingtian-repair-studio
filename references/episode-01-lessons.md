# 第1集实施经验（历史案例，不是永久参数）

日期：2026-10-15。第1集主题“这个闹钟，能不能跳过周一？”。计划16镜、约60秒，最终成片62秒，含2秒片尾，1280×720/30fps。

## 真实问题与采取的方式

| 问题 | 可复用决策 |
| --- | --- |
| 左下前臂两次仍未补全 | 明确需要连续延伸至画外的前臂结构，实际检查修图结果，不能仅说“修好了” |
| 第06镜首帧与脚本不符 | 用户同意借用第09镜双人全景；第07镜改从画面左上固定位置送纸。这是本次明确批准的替代，不授权所有未来借图 |
| 03出现真人、08吐司提前缺口、09动作不符、11电池重复、15多余人物/文字、16电池重现 | 逐镜状态检查比“生成成功”重要。重做模型当时选择Seedance 2.0 Mini 720p/4秒，价格只是历史 |
| 7镜返工报价168积分、14句配音14积分 | 用户当轮批准上限182积分；13生成失败，不保证退款，不得沿用该上限到新一集 |
| 13失败 | 用4秒稳定静帧备用，最终缓慢移动镜头；不隐瞒缺少原计划动作 |
| 11返工仍出现真人手 | 成片改为卡通首帧1.1秒接空电池仓1.9秒，以声音和结果表达取电池；不是成功生成了完整拔电池动作 |
| 订单、日历、营业牌中文不可靠 | 使用干净关键帧加后期中文：委托问题、周一/又是周一、补充需求、早八营业→十点开门 |
| 剪映调整视频长度带动字幕，粘贴13变叠加覆盖14 | 先检查联动/磁吸/锁定，验证所有轨道的衔接；总时长并不能证明正确 |
| UI操作较慢，最终使用本地字幕/混音/片段准备再入剪映导出 | 真实交付了MP4；新剪映工程是整段合成素材，不代表完整可编辑的多轨工程 |

最终加入轻柔拨弦伴奏、滴答加速、纸声、碰撞、断电停顿与尾部闹铃。旧生成原声与对白不混用。配音按实际时长生成字幕，并补准确画内字。检测确认可解码、无检测到的黑帧、峰值未削波；这些检查不等价于全程人工视听审片。
