# 第2集：这盏灯越催越精神——可复用实施经验

## 1. 接续工作先核实文件，不重新生成
- 检查当前集的脚本、关键帧、各版本视频、声音和成片；用户说“缺的视频已生成”时重新扫描并验证，不凭旧任务状态重复计费。
- 每镜维护：镜号、源文件、SHA256、首帧SHA256、生成工具/模型、实际帧率/帧数/时长、音轨状态、质量结论、采用版本与理由。
- 本集01/04有即梦v2替换旧Hy3版；不能只按文件名最高版本或日期自动采纳。核对用户选择并检查实物。已保留的旧版不删除。
- 本集画布旧首帧与本地批准图曾不一致。提交前核对上传来源和哈希；任务成功不等于用了正确首帧。
- WorkBuddy是运行环境，Hy3是其中的模型；不能假定任意环境可直接调用。交接文档包括剩余镜号、绝对路径、每镜提示词、起止状态、声音要求、预算授权范围、禁止重生成项和验收条件。区分生成失败与成功后下载失败，后者优先恢复下载。

## 2. 逐镜验收与低成本修复选择
- 起点、中段、终点都检查，关键变化附近加密抽帧；固定机位检查中途推拉，人物检查耳朵、脸部、身体条纹与肢体，故事道具检查声波图标、纸张和持物关系。
- 第2集09镜声波图标在视频中变形，采用批准关键帧作短静态特写并后期加入“声控感应”。用于读信息的镜头可静态；承担必要动作的镜头不能用静帧冒充动作完成。
- 第2集08镜后段形变，仅保留稳定段；11镜中段人物变形，采用稳定起始画面表现安静等待。静帧停留必须服务于剧情停顿，记录替换方式，不能把它称为重新生成的动态镜头。源首帧不合格时禁止沿用。
- 若静帧、裁去坏段或局部修补破坏因果/节奏，则提交修复或重新生成方案；费用超出已授权上限时先报价确认。
- 本集Hy3素材出现“AI生成”标识是历史观察，不推断所有版本服务都有相同表现。记录实际标识，不以绕过来源标识为修复目标；发布声明独立处理。

## 3. 灯光变化是局部叙事事件
- 明确时间顺序：声音触发→亮度升级；安静等待→熄灭；欢呼→重新点亮。音效跟随触发点，不能由音乐或旁白无意打破“安静”的故事逻辑。
- 第2集14镜原视频把整个房间压暗，后期改为仅熄台灯并减少桌面光晕，保留环境照明。对照变化前后，检查人物脸、窗光和房间曝光。
- 可用同机位、同尺度、同透视的关灯状态参考做羽化局部替换；先配准，不直接套用其他镜头坐标。镜头或人物运动时需要跟踪遮挡，不能硬贴静态补丁。
- FFmpeg maskedmerge 的遮罩要覆盖所处理的颜色平面。仅正确处理亮度而色度不匹配会产生彩色残影；本集统一yuv444p并给各平面相同空间/时间权重后修正。抽查过渡起、中、末及原尺寸局部。
- 历史光晕中心、羽化半径、0.3秒渐变等不设为通用常量。新的灯、镜头与分辨率都重新确定参数。

## 4. 声音、字幕与时间轴只用一份最终依据
- 逐句配音独立保存，角色音色先固定；第2集沿用阳光小男孩/低沉大叔，仅当当前服务仍提供且用户满意时复用。
- 配音与音效分开保存；检查生成视频自带音轨，避免把模型乱语与正式对白混在一起。是否保留环境音根据实际试听决定，不把无音轨称为有底噪。
- 先确定输出帧率和每镜帧数，再累计镜头起点；对白按“镜头新起点+镜内偏移”重新定位，字幕由实际配音时长生成。若调整镜内动作，偏移也要重算。
- 第2集源时长累计约58.333秒，按30fps处理后约58.467秒，旧字幕不能无条件复用。输出11句是本集事实，不是下一集固定句数。
- 尾梗前安静段不铺持续音乐；少量亮灯提示音、开场短音与动作音即可。无可用版权素材时可原创合成简单提示音，但不把合成音说成实录或配乐库授权音。
- 保存逐句WAV、角色分轨、对白/音效分轨、最终混音、最终对白时间JSON、同步SRT；交付前检查丢句、重叠、峰值及尾字，音质/读音仍需实际试听。未听音时明确检查范围。

## 5. 剪映导出与交付
- 用户要求剪映时，完成本地准备后仍实际导入剪映并导出，确认成功提示；保留用户已有工程。压平合成片另开工程时如实说明，不能声称它是逐轨可编辑项目。
- 本集UI拖拽未成功，素材缩略图的添加按钮成功。每次操作后看实际轨道、总时长和画面，不把点击或拖拽本身当成成功。截图暂态显示需刷新验证，不能根据未加载的数值乱改缩放。
- 原画720p可按1280×720、30fps、H.264/AAC导出；不为“高清”盲目上采样。本集导出58.468秒约36.2MB只是验收结果。
- 原始导出可能仍使用日期工程名。复制为可识别的系列/集数/主题/发布版文件名，用临时文件+哈希校验+原子移动落盘；给用户一个主MP4，不让其在多个临时版本里猜。
- 检查实际剪映导出文件而非仅检查中间渲染：完整解码、分辨率/帧率/时长/音轨、黑帧、关键画面与同步。技术通过、抽帧通过、完整试听分别记录，不互相冒充。
