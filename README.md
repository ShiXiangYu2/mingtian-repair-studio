# 明天修理铺 · 动画短视频技能包

版本：**1.2.0**。用于《明天修理铺》系列的主题、剧本、角色场景、七列Excel分镜、关键帧、视频、配音字幕、后期成片与发布封面。

## 使用

将本仓库下载到本地候选目录，审阅 SKILL.md 及文件后，交给支持本地 skills 的助手安装。Codex目标目录为 `~/.codex/skills/mingtian-repair-studio`；已有版本先备份，勿直接覆盖。安装和更新需要用户对当前候选明确同意。

示例：
- 用明天修理铺技能创作新一集，先交剧本和分镜表。
- 根据已有关键帧生成分镜视频，先核对模型费用和预算。
- 只修影响剧情的镜头，保留可通过剪辑调整的素材。
- 完成配音、字幕与后期，交付可发布MP4和横竖封面。

## 能力与依赖

技能本身是创作与执行规范，不包含生成服务、账号、额度或角色图片。需要使用者自行提供角色/场景参考、当前模型工具及授权。图像生成、表格、即梦、Neowow、剪映电脑操作按任务选用对应能力；缺少某项时说明限制，不自动安装或付费。

Python 3用于随包脚本；Excel模板脚本需要openpyxl。维护安装脚本依赖Windows PowerShell；macOS/Linux用户可阅读规范，但不要直接运行Windows安装步骤。项目位置由使用者指定。

## 来源与校验

此仓库是已安装v1.2.0的公开分发副本，去除了个人绝对路径和外部项目证据清单，未包含API密钥、账号配置、视频、声音或角色素材。来源摘要见sources，来源哈希见manifest.json，公开文件哈希见CHECKSUMS.json。

在仓库根目录运行：
```text
python scripts/lifecycle.py audit --skill .
python scripts/lifecycle.py check-sources --skill .
```

check-sources只检查记录的本地来源，不代表已查GitHub最新版本。部署前可用plan生成候选差异，收到针对该候选的人类批准后才执行install；approval校验值不能替代批准。

公开可查看不等于授予额外授权；本仓库暂未指定开源许可证。角色素材和模型服务不随包授权。
